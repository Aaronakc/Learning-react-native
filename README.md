#  React Native Firebase Todo App Suite

Welcome to my **React Native learning repository** , a journey through building mobile apps with real functionality!  
This repo contains multiple sub-projects covering **UI design**, **Firebase integration**, **authentication**, **Firestore-based todo management**, **local notifications**, and more.

---

## 📁 Project Structure

### 1.  [`uiDesignProject/`](./uiDesignProject/README.md)
> **Login / Sign Up UI Design Only**
- Focused purely on frontend layout.
- Clean design using React Native components and styling.
- No backend or Firebase functionality included.

📁 Relative Path: `./uiDesignProject`

---

### 2.  [`TodoApp/`](./TodoApp/README.md)
> **Todo App with Full Firebase Backend**
- Email/Password authentication using **Firebase Auth**.
- Create, update, complete, and delete todos.
- Uses **Firebase Firestore** for real-time storage and sync.
- Scheduled **local notifications** using **Notifee**.
- Editable **user profile details** with Firestore sync.
- Advanced navigation (Drawer, Bottom Tabs, Material Top Tabs).

📁 Relative Path: `./TodoApp`

---

## Tech Stack

- React Native (CLI)
- Firebase Authentication
- Firestore Database
- Notifee (Local Notifications)
- React Navigation
  - Drawer Navigator
  - Bottom Tabs
  - Material Top Tabs
- Toast Notifications
- Redux (used in earlier phase)
